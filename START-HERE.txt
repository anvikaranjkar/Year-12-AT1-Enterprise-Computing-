ENTERPRISE STUDY STUDIO 2.4.0

This is the small upload package with highlighting and saved booklets.
All included files are under 100 KB. Large original PDFs/screenshots open
through source links in your ChatGPT account. The interactive study app,
notes, quizzes, four mocks and seven spreadsheet workbooks are included.

TO STUDY
Extract the ZIP, then open index.html inside the extracted folder.
Read README.md if your browser needs a local server to save progress.

TO UPLOAD
1. Use a new empty GitHub repository for this lightweight version.
2. Choose Add file > Upload files.
3. Drag all FILES and the resources FOLDER from this package into GitHub.
4. index.html must appear at the repository root.
5. Do not upload the ZIP itself or the larger parent project folder.
6. In Vercel import the repository. Choose Other. Leave Build Command
   empty. Use . as Output Directory if an override is required.

HIGHLIGHTING AND BOOKLETS
Open Learn & revise, the cheat sheet or a graph guide. Select text,
choose a highlight colour and destination, then press Save highlight.
Save whole note keeps a complete text copy. Open Booklets in the sidebar
to create collections, annotate, search, move items, export and print.

Before changing your study URL, use Resources > Export progress backup.
Highlights and booklets are included in that backup. They are saved on
this browser only, so keep a backup to protect them or move devices.

The site is prepared for deployment, not already deployed to your account.
